## Usage Guidelines

### General Rules

1. **Lazy Loading:** All images must use `loading="lazy"` attribute
2. **Dimensions:** Always specify `width` and `height` to prevent layout shift
3. **Format:** Serve WebP with JPEG fallback using `<picture>` element
4. **Compression:** Maintain 85%+ quality, target <200KB per image
5. **CDN:** All images served via Cloudflare Pages CDN

### Article Integration

- **Hero images:** Use IMG-001, IMG-003, IMG-007 for category landing pages
- **In-content images:** Rotate IMG-002, IMG-004, IMG-005, IMG-006, IMG-008, IMG-009, IMG-010 within article bodies
- **OG images:** Use IMG-001, IMG-003, IMG-005, IMG-007, IMG-009 for social sharing

### Accessibility

- All alt texts comply with WCAG 2.1 Level AA
- Alt texts are descriptive, not functional ("what" not "how")
- No redundant phrases like "image of" or "photo of"
- Color contrast meets 4.5:1 ratio for any text overlays

### Future Expansion

- Naming system supports adding new product types: `{new-type}-{feature}-{market}-{seq}.webp`
- Image IDs follow sequential numbering (IMG-011, IMG-012, etc.)
- New markets can be added: JP, KR, DE, FR, CA, etc.
